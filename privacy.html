Hermes Google Drive

개인정보처리방침

이 방침은 운영자의 Google 계정을 Hostinger Managed Hermes에 연결하여 문서 작업을 수행하는 개인용 앱에 적용됩니다.

앱 소개일반 문의 (GitHub)

1. 운영자와 적용 범위

앱 운영자는 cloudpurple이며, 일반 문의는 GitHub 문의 페이지에서 받습니다. 현재 사용 기능은 Google Drive, Docs, Sheets 연동입니다. 이 앱은 개인이 관리하는 Hermes 환경에서 사용하며, 공개 가입형 서비스가 아닙니다.

GitHub 문의 내용은 공개됩니다. 개인정보, 문서 내용, 인증 코드 또는 토큰을 게시하지 마세요. 민감한 내용을 포함하는 문의는 Google 동의 화면에 표시된 사용자 지원 이메일을 확인하여 연락해 주세요.

2. 접근하는 정보와 목적

정보이용 목적
Google Drive 폴더·파일 정보와 파일 내용요청한 파일 검색, 내려받기, 업로드, 정리 및 문서 작업
Google Docs 문서 내용문서 열람, 작성, 편집 및 요청한 요약
Google Sheets 표와 셀 데이터시트 열람, 작성, 편집 및 요청한 계산·분석
OAuth 접근 토큰·갱신 토큰 및 클라이언트 자격증명승인된 Google API 연결 유지와 자동 접근 토큰 갱신

Google 계정 비밀번호는 이 앱에서 수집하지 않습니다. Google 계정 연결은 Google OAuth를 사용합니다. 기존 자료에 접근할 수 있는 권한을 승인했더라도 실제 작업 대상은 운영자의 요청과 설정된 작업 범위에 따라 선택합니다.

Calendar, Gmail, Contacts 정보는 현재 연결 기능에 포함하지 않습니다. Calendar를 추가하는 경우 일정 정보와 처리 목적을 안내하고 필요한 추가 권한을 승인받은 뒤 사용합니다. 기능 또는 정보 이용 목적이 바뀌면 이 방침과 작업 안내를 갱신합니다.

3. 정보의 처리·저장 위치

원본과 작업 산출물은 운영자가 지정한 Google Drive 위치에 보관합니다. OAuth 자격증명은 앱을 실행하는 Hostinger Managed Hermes 환경에 보관합니다. 작업에 필요한 임시 파일, 대화, 메모리, 실행 기록은 Hermes와 호스팅 설정에 따라 해당 운영 환경에 저장될 수 있습니다.

이 공개 안내 사이트에는 OAuth JSON, 접근 토큰, Google 문서 또는 업무 파일을 업로드하지 않습니다. GitHub Pages는 안내 페이지를 제공하며, GitHub가 사이트 제공 및 보안을 위해 방문 접속 정보를 처리할 수 있습니다. GitHub의 처리 방식은 GitHub 개인정보처리방침을 참고해 주세요.

4. AI 제공자와 제3자 처리

문서의 AI 요약·분석·작성을 요청하면 필요한 내용이 Hermes에 설정된 외부 AI 제공자에게 전달될 수 있습니다. 단순히 Google OAuth를 직접 연결했다고 해서 문서의 AI 처리까지 Google과 Hostinger 안에서만 이루어지는 것은 아닙니다.

AI 제공자는 실제 Hermes 모델 설정에 따라 결정됩니다. 운영자는 처리 전에 제공자와 전달할 자료 범위를 확인하고, 그 제공자의 데이터 보관·학습 이용 조건을 확인합니다. 회사 기밀이나 타인의 개인정보를 처리할 때에는 해당 자료의 처리 권한과 적절한 제공자 설정을 확인한 범위에서 사용합니다.

운영자는 Google 사용자 정보를 판매하거나 광고 타기팅에 사용하지 않습니다. Google API로 얻은 정보의 이용과 제3자 전달은 Limited Use 요건을 포함한 Google API Services User Data Policy를 따릅니다. 제공자별 보관 조건까지 일률적으로 동일하다고 보장하지 않습니다.

5. 보관과 삭제

Google Drive의 원본과 산출물은 운영자가 정한 보관 규칙에 따라 유지하며, 삭제 요청에 따라 처리합니다. Google 연결을 해제하는 것만으로 이미 작성된 문서나 Hermes 작업 기록이 자동 삭제되지는 않습니다.

연결 해제 시 앱 운영 환경의 토큰 삭제와 Google 권한 철회를 함께 처리할 수 있습니다. 임시 파일, 대화·메모리 및 기록의 삭제 범위는 운영자의 요청과 실제 시스템 설정을 확인하여 처리합니다.

Hostinger 자동 백업과 운영자가 별도로 내려받은 백업에 정보가 남아 있을 수 있습니다. 백업 사본은 그 보관 정책 및 운영자의 삭제 절차에 따라 처리하므로 즉시 모든 사본이 사라진다고 보장하지 않습니다.

6. 보호와 권한 철회

운영자는 자격증명을 공개 저장소나 안내 사이트에 게시하지 않고, Hermes 환경의 접근 권한과 파일 권한을 관리합니다. 문서 삭제, 외부 공유, 기존 파일 덮어쓰기는 승인된 요청에 따라 수행합니다.

연결 권한은 Google 계정의 연결된 앱 관리에서 확인하거나 철회할 수 있습니다. 데이터 접근·정정·삭제 또는 이 방침에 관한 일반 문의는 GitHub 문의 페이지에서 접수할 수 있습니다. 계정·문서·인증정보를 포함하는 요청은 Google 동의 화면의 사용자 지원 이메일로 전달해 주세요. 본인이 운영하는 앱의 자료 삭제는 기존 Hermes 대화에서 지시할 수 있습니다.
